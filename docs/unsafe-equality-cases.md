# GHC's late unsafe-equality case rule

The exporter applies GHC 9.14.1's own `GHC.Core.Utils.isUnsafeEqualityCase` predicate to the original typed Core case, before erasing type/coercion arguments or binder occurrence information. This is the same rule used by `GHC.CoreToStg.coreToStgExpr`: one `UnsafeRefl` data alternative, a dead case binder, and the actual wired `unsafeEqualityProof` identity applied to its three arguments. A matching case exports its RHS. The optimized GHC program itself is not mutated or resimplified.

The surviving expression keeps the case's result representation and its source notes. Its `unsafeEqualityCase` metadata records the exact late rule; the optional `pretty-diagnostics` export includes the original Core in `sourceCore`. Interface dependency discovery applies the same predicate, so erased proof cases do not create a spurious dependency on an unavailable executable proof body. No runtime primitive, synthesized proof value, or name-based alias is added.

A bare proof, live case binder, wrong callee, or wrong alternative does not match. GHC's original `unsafeEqualityProof` source is deliberately self-recursive before CoreToStg, and supplying that unlowered body is not evidence of working execution. This rule does not supply a general first-class proof definition. Ordinary nonmatching cases still evaluate their real scrutinee; a nonmatching callee keeps its original effects and exceptions.

Pinned primary sources: [Core.Utils predicate](https://gitlab.haskell.org/ghc/ghc/-/blob/ghc-9.14.1-release/compiler/GHC/Core/Utils.hs#L3050), [CoreToStg use](https://gitlab.haskell.org/ghc/ghc/-/blob/ghc-9.14.1-release/compiler/GHC/CoreToStg.hs#L459), and [Unsafe.Coerce implementation notes](https://gitlab.haskell.org/ghc/ghc/-/blob/ghc-9.14.1-release/libraries/ghc-internal/src/GHC/Internal/Unsafe/Coerce.hs).
