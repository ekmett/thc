# JSON package fixture

This handwritten scalar module exercises loose, ordered and reordered ZIP
package inputs through both backends. Expected results are `x + 1` for zero
and `x + 2` otherwise. The fourth body is deliberately unusable and must remain
unprepared. This is a checked runtime model, not exported GHC Core.
