# Explicit consumer sidecar controls

`indexed-consumer.json` and `indexed-interface-closure.json` are hand-written
runtime controls, not GHC exports. The consumer applies the interface fragment's
`dependency:Hidden.cold` to its argument; the independent expected result is
the argument plus three. The fragment deliberately keeps the original binding
owner and declares the complete `synthetic:LazyJson` support module separately.

The checked-in `.idx` files were generated by the production native
`thc-json-index` executable from producer checkpoint
`372c49b2ab7039bc17c4576c12ef4f979ed37d4b`, using:

```sh
thc-json-index indexed-consumer.json indexed-consumer.idx
thc-json-index indexed-interface-closure.json indexed-interface-closure.idx
```

The executable SHA-256 was
`88eb3c12036fe7262d9fb3f31016e1d6bb8ad021f245bc3f74205fb205be3942`.
`CoreJsonConsumersTest` pins all four input hashes and loads the native sidecars
directly. There is no reference-scanner fallback. Regenerate the sidecar after
changing JSON; never update its embedded source identity independently.
